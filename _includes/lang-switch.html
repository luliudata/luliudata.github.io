{%- comment -%} Renders a single-character language switch that mirrors the light/dark toggle: on English pages it shows "中" (click to go Chinese); on Chinese pages it shows "EN" (click to go English). From an English URL we prepend /zh; from a Chinese URL we strip the leading /zh. Pages without a translated sibling will land on the site's 404 — acceptable for now since the language switch on a post implies a translation exists. {%- endcomment -%} {%- assign current_lang = page.lang | default: site.lang | default: "en" -%} {%- if current_lang == "zh" -%} {%- assign other_lang = "en" -%} {%- assign other_url = page.url | remove_first: "/zh" -%} {%- if other_url == "" -%}{%- assign other_url = "/" -%}{%- endif -%} {%- else -%} {%- assign other_lang = "zh" -%} {%- if page.url == "/" -%} {%- assign other_url = "/zh/" -%} {%- else -%} {%- assign other_url = "/zh" | append: page.url -%} {%- endif -%} {%- endif -%} {{ site.data.i18n[current_lang].switch_to }}
