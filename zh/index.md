你好，我是 Lu，一名 **数据与 MLOps 工程师**。我的工作是搭建机器学习
模型从训练到上线的整套平台和流水线，主要在 AWS 上（SageMaker、
Step Functions、Glue、CodeBuild/CodePipeline），配合 Terraform、
Python 和 Spark。我相信好的 ML 平台应该让建模同事能放心地把模型
交给生产环境 —— 一切都可复现、可观测，"无聊"得让人安心。

在做这份工作之前，我在金融与数据分析领域担任高级软件工程师，
为数据科学团队搭建过基于 AWS 的内部平台，也把 NLP 和分析师修订
模型从原型推进到生产。我持有 **AWS 机器学习专项认证**，
活跃于 AWS 技术社区，最近也在探索 agentic systems，
拿到了 agent-skills 认证。

工作之外，我教编程入门、做女性技术社群的 mentor，
偶尔会在技术 meetup 上分享。我还在做一款叫
**[随行 Notes](/zh/projects/#triptracker-notes)** 的 iOS 旅行应用 ——
双语、注重隐私，能用 AI 生成行程建议。

博客以学习笔记为主，话题大致围绕 MLOps、AWS、AI agents
和一些副业项目。欢迎留言交流，
评论、勘误、建议都非常欢迎。
